ClipForge

ClipForge is a personal Windows desktop app. It turns the owner's own long videos into short clips and, when the owner chooses, posts them to the owner's own TikTok and YouTube accounts on a schedule using the official TikTok Content Posting API and YouTube Data API.

ClipForge is not a public service. It runs only on the owner's computer and is used only with the owner's own accounts.
